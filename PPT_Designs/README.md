# PPT_Designs

Reference pictures of slide designs. They were **studied** — shapes, fonts, placement,
decorative details — and the findings were rebuilt as six original design families in
`families.py` (see `DESIGN_NOTES.md`). The app does not read these pictures at run time.

Add more references here if you want new families designed from them.

The images are not committed to git (only this README is tracked).
